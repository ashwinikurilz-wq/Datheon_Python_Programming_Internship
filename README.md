# Datheon Python Programming Internship

This repository contains my Python programming internship projects for Datheon.

## Task 1: Hangman Word Guessing Game
- Built a console-based word guessing game.
- Includes ASCII hangman stages and six incorrect guesses.
- Tracks guessed letters and prevents duplicate-guess penalties.
- Displays win and game-over messages.

**Run:** `python hangman.py`

## Task 2: Stock Portfolio Performance Tracker
- Accepts stock tickers, purchase prices, quantities, and current prices.
- Calculates invested capital, market value, and gain/loss percentages.
- Exports portfolio holdings to a CSV file.
- Current prices are entered manually in this version.

**Run:** `python portfolio.py`

## Task 3: Automated File Organizer
- Organizes files into folders based on file extensions.
- Handles duplicate filenames and filesystem errors.
- Displays a summary of file operations.

**Run:** `python organizer.py`

## Requirements
- Python 3
- Python standard library

## How to Run
1. Download or clone this repository.
2. Open the relevant task folder in VS Code or PyCharm.
3. Run the Python script using the commands listed above.
4. Follow the prompts shown in the terminal.

## Note
Run file-organizer tests on a test directory containing sample files before using it on personal folders.
