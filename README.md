## Projects / Tasks

### Task 1: Hangman Word Guessing Game (Console)

A text-based word guessing game developed using Python.

**Features**
- Random word selection.
- Six attempts to guess the word.
- ASCII hangman stages.
- Displays correctly guessed letters.
- Prevents repeated guesses from counting as new attempts.
- Displays win or lose messages.

**Technologies:** Python, `random`

**How to Run**
```bash
python hangman.py
```

### Task 4: Rule-Based Interactive Terminal Chatbot

A rule-based customer support chatbot that uses predefined responses, regular expressions, and an external JSON file to answer common questions.

**Features**
- Responds to greetings.
- Answers frequently asked questions.
- Provides internship project submission information.
- Answers questions about business hours and certificates.
- Handles unrecognized questions with a fallback response.
- Supports exit commands such as `bye`, `exit`, and `quit`.
- Loads FAQ data from `sample_faq.json`.

**Technologies:** Python, `re`, `json`

**How to Run**
```bash
python chatbot.py
```

Ensure that `sample_faq.json` is in the same directory as `chatbot.py`.
